## Backend audits

| Audit | Result |
| --- | --- |
| IR semantics probes (`tests/semantics.sh`): integer widths 1 to 128, float, double, x86_fp80 | 44,762 probes bit-identical to native in managed-host, system and portable JIT and portable NativeAOT |
| Vectorized builds (`tests/vector-sweep.sh`): -O3 vectorize, fast-math, -march=x86-64-v3 | 20 of 20 builds match native, none rejected |
| Linkage (`tests/linkage.sh`) | aliases, weak overrides, undefined weak, ELF archive rules, alias exports, ifunc rejection match native in all modes |
| Termination order (`tests/exit-order.sh`) | matches glibc for return and `exit()` in all modes, JIT and NativeAOT |
| Determinism (`tests/determinism.sh`) | repeated C, C++ and Fortran builds byte-identical in both ABIs, including native bridges |
| Support matrix (`docs/user/support-matrix.md`) | 162 of 212 constructs translated, the rest rejected with diagnostics, no internal errors or invalid IL |

Behavior bugs the audits found and fixed: wide float-to-int conversions that threw on legal or poison inputs; x86_fp80 stores clobbering the 6 bytes after the value (and loads reading past it); long double `lround`/`llrint`/`is.fpclass` emitting invalid IL; C `atexit` handlers running after C++ static destructors; system-mode `exit()` skipping every handler and destructor; output names such as `System.dll` silently colliding with framework assemblies. Missing features added: 65- to 128-bit `abs`, min/max, `bitreverse`, funnel shifts and saturating operations; 128-bit atomics; masked memory intrinsics from AVX2 vectorization; constrained floating-point intrinsics; global aliases and undefined weak symbols.

## libc++ and libc++abi 22.1.8 (CX-01)

All 66 selected sources compile. A smoke program covering containers, streams, `std::format`, regex, exceptions, `exception_ptr`, threads, futures, filesystem and random engines matches native under JIT and NativeAOT (2.3 MB assembly, 1,373 methods, 0 P/Invoke imports). 11 existing C++ fixtures match. Differences: the `random-device` fixture uses the libstdc++-only token `"default"`; two fixtures assume glibc's order of main-thread `thread_local` destructors before `atexit` handlers, which libc++abi's fallback does not give without `__cxa_thread_atexit_impl` (CX-12).

## flang-rt 22.1.8 (FT-01)

All 67 sources compile in about 25 s. 34 single-file Fortran fixtures match native Flang, `namelist` also under NativeAOT. The `random` fixture differs only for `REAL(4)`, because flang-rt draws those values through `uint_fast32_t`, which is 64-bit in glibc and 32-bit in musl.
