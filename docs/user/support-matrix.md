# LLVM IR support matrix

Generated by `scripts/support-matrix.py`; do not edit by hand. After changing the backend, run `tests/run.sh support-matrix`, which fails and regenerates this page when it is out of date.

Each row is a small LLVM IR module compiled with `llvmnet --runtime=portable`. **Translated** means llvmnet produced CIL for it and the JIT accepts every method. Execution correctness is checked separately by `tests/semantics.sh`, which compares generated operations bit for bit with native code, and by the fixture tests. **Rejected** rows show the diagnostic a user sees.

184 of 212 constructs are translated.
