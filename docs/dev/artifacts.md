# The `artifacts/` directory

Everything generated by builds, tests and workload scripts lives under `artifacts/`, which git ignores. Nothing under it is a source of truth for the repository. This page says what each part is, so it is clear what can be deleted.

| Path | Kind | Produced by | Safe to delete |
| --- | --- | --- | --- |
| `vendor/downloads/` | Cache of pinned upstream archives | `scripts/fetch-sources.sh` | Yes; downloaded and verified again on demand |
| `vendor/src/<name>-<version>/` | Extracted pinned sources | `scripts/fetch-sources.sh` | Yes |
| `vendor/musl-native/` | Debian's musl, the native oracle for musl tests | `scripts/musl-native-cc.sh` | Yes |
| `vendor/openmp/` | Downloaded OpenMP packages | `scripts/install-system-openmp.sh` | Yes |
| `tools/csmith/`, `tools/yarpgen/` | Fuzzing program generators built from pinned sources | `scripts/build-fuzzers.sh` | Yes; rebuilt on demand |
| `tests/<name>/` | Per-test scratch output | each `tests/*.sh` script | Yes |
| `tests/results/` | Test runner results: per-test logs, `summary.tsv`, `results.xml` | `tests/run.sh` | Yes, once read |
| `sysroot-build/dotnet64-v2/` | Build trees and per-file logs of the sysroots (musl, libc++, flang-rt) | `scripts/build-sysroot.sh` | Yes; the installed sysroots are `sysroot/dotnet64-v2/` and `sysroot/system-linux-x64-v1/` outside `artifacts/`, also generated and ignored by git |
| `deps-<mode>/`, `deps-build-<mode>/` | Dependency install prefixes and build trees, one per runtime mode | `scripts/build-dependencies.sh` | Yes |
| `ffmpeg-*/` | ffmpeg build trees, decode harnesses and frame records | `scripts/build-ffmpeg.sh`, `scripts/build-ffmpeg-core.sh` | Yes |
| `toolchain/`, `*-toolchain*/` | Packaged toolchain installations | `scripts/package-toolchain.sh` | Yes, unless a SPEC run uses one |
| `system-cxx/`, `system-openmp/` | Optional system-mode libraries | `scripts/build-system-cxx.sh`, `scripts/install-system-openmp.sh` | Yes |
| `perf/` | Runtime benchmark builds and `runtime.tsv` | `scripts/bench-runtime.sh` | Yes |
| `video-simd128*/` | Video validation and measurement records | `scripts/benchmark-simd128.mjs` | Yes, once read |
| `spec2017/`, `spec2026/`, `spec*-harness/` | Installed licensed SPEC kits | manual installation | Only if the kit media is still available; never committed |
| `spec-matrix/`, `spec-ordered/`, `spec-portable-audit/` | SPEC results with frozen scripts, logs and hashes | `scripts/spec-*.sh` | Yes, once read; `scripts/spec-portable-audit.mjs` and `scripts/spec-summary.sh` read them |
| `doc-results/` | Local measurements and run results kept out of the documentation, one file per document | manual | Yes |
| `*.log` at the top level | Logs of manual runs | manual | Yes |

`scripts/clean.sh` deletes `tests/`, `sysroot-build/`, `deps*/`, `ffmpeg-*/`, `*-toolchain/` and `*-toolchain-*/`. `--downloads` also deletes `vendor/`, and `--all` deletes everything under `artifacts/`. `--dry-run` lists what would be deleted. The script never touches anything outside `artifacts/`.
