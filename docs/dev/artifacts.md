# The `artifacts/` directory

Everything generated by builds, tests and workload scripts lives under `artifacts/`, which is ignored by git. Nothing under it is a source of truth for the repository. This page says what each part is so it is clear what can be deleted.

| Path | Kind | Produced by | Safe to delete |
| --- | --- | --- | --- |
| `vendor/downloads/` | Cache of pinned upstream tarballs | `scripts/fetch-sources.sh` | Yes; re-downloaded and re-verified on demand |
| `vendor/src/<name>-<version>/` | Extracted pinned sources | `scripts/fetch-sources.sh` | Yes |
| `vendor/libcxx/`, `vendor/openmp/` | Debian packages staged without root | `scripts/install-libcxx-headers.sh`, `scripts/install-system-openmp.sh` | Yes |
| `tests/<name>/` | Per-test scratch output | each `tests/*.sh` script | Yes |
| `tests/results/` | Test runner results: per-test logs, `summary.tsv`, `results.xml` | `tests/run.sh` | Yes, after the evidence has been read |
| `portable-runtime/` | Intermediate portable C++ support objects | `scripts/build-portable-runtime.sh` | Yes |
| `deps*/`, `deps-build*/` | Dependency install prefixes and build trees, one per ABI | `scripts/build-dependencies.sh` | Yes; rebuilt by the integration tag |
| `ffmpeg-*/` | ffmpeg build trees, decode harnesses and frame records | `scripts/build-ffmpeg*.sh` | Yes; the video validation evidence inside is regenerated by the scripts |
| `deploy-toolchain/`, `*-toolchain*/` | Packaged toolchain installations | `scripts/package-toolchain.sh` | Yes, unless a SPEC matrix is running against one |
| `system-cxx/`, `system-openmp/` | Optional system-mode libraries | `scripts/build-system-cxx.sh`, `scripts/install-system-openmp.sh` | Yes |
| `spec2017/`, `spec2026/`, `spec*-harness/` | Installed licensed SPEC kits | manual installation | Only if the kit media is still available; never committed |
| `spec-matrix/`, `spec-ordered/`, `spec-portable-audit/` | SPEC evidence with frozen scripts, logs and hashes | `scripts/spec-*.sh` | Keep while it is cited by `docs/spec-*.md` |
| `*.log` at the top level | Historical gate logs cited by `docs/` | manual runs during bring-up | Keep while cited |

`scripts/clean.sh` deletes the disposable categories. It keeps SPEC kits, SPEC evidence and cited logs unless `--all` is given, and it never touches anything outside `artifacts/`.
