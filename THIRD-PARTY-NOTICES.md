## Copied next to every emitted program

The compiler copies these files beside each `.dll` or launcher payload it emits, so they are redistributed whenever a compiled program is redistributed:

- `LlvmNet.Runtime.dll`: part of llvmnet, MIT. When `LlvmNet.Runtime.dll` is shipped as a separate file, include `LICENSE.TXT` with the program.
- For `--runtime=portable` outputs, the parts of musl (MIT), libc++, libc++abi, the OpenMP runtime, flang-rt and the compiler-rt builtins (Apache-2.0 WITH LLVM-exception) the program uses, compiled into its CIL. Include `musl.COPYRIGHT` from the sysroot with a redistributed program; the LLVM exception covers the LLVM parts.
- For `--runtime=system` outputs, the parts of flang-rt a Fortran program uses, compiled into its CIL, and, for JIT outputs, a generated `lib<name>.llvmnet-host.so` bridge. The bridge contains only code generated by LLVM from the program's own call signatures.

NativeAOT executables also embed the .NET runtime (MIT; include its `LICENSE.TXT` and `THIRD-PARTY-NOTICES.TXT` when redistributing) and, in system mode, the generated bridge.
