It is installed as `share/llvmnet/THIRD-PARTY-NOTICES.md` by `scripts/package-toolchain.sh`.

## Copied next to every emitted program

The compiler copies these files beside each `.dll` or launcher payload it emits, so they are redistributed whenever a compiled program is redistributed:

- `LlvmNet.Runtime.dll`: part of llvmnet, Apache-2.0 WITH LLVM-exception. The LLVM exception covers portions of the runtime embedded into a program's object form, such as NativeAOT executables. When `LlvmNet.Runtime.dll` is shipped as a separate file, include `LICENSE.TXT` with the program.
- `MathNet.Numerics.dll`: MIT. Include the MIT notice below with the program.
- For `--runtime=system` JIT outputs, a generated `lib<name>.llvmnet-host.so` bridge. It contains only code generated by LLVM from the program's own call signatures.

NativeAOT executables additionally embed the .NET runtime (MIT) and the native helper archive.
